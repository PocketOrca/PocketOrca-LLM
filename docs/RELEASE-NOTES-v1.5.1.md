# PocketOrca-LLM v1.5.1 更新日志

本次更新，把这个 App 从「服务聚合器」再往前推一步：手机本地现在也是一个知识库服务。

新增内置 RAG 知识库服务（:8082），与搜索服务同款独立形态——独立端口、独立通知、独立 Key，可直接为第三方 Agent / 客户端提供检索与嵌入能力。

## 一、知识库服务

标准接口：`/v1/rag/{status,index,search,drop}`，另暴露 `/v1/embeddings` 兼容接口，外部脚本可直接调用

独立形态：默认端口 8082（不与 8080/8081 冲突），独立前台服务与通知通道，启停不影响推理与搜索服务

内置嵌入模型：bge-small-zh-v1.5（Q8，约 26MB，随包不下载），独立小进程按需拉起、空闲 5 分钟自动回收；

指纹增量：mtime+size 快判 → sha256 真判；未变文件毫秒级跳过（实测重复索引 7ms），文件变更会提示重建

### 支持的文件格式

按扩展名白名单收录，共 31 种，其余一律跳过：

| 类别 | 扩展名 | 切块方式 |
|---|---|---|
| 文档 | .md .markdown .mdx .rst .adoc | 按标题层级切，块内保留标题路径 |
| 纯文本 | .txt | 约 700 字滑动窗口，70 字重叠 |
| 代码 / 配置 | .java .kt .py .js .ts .tsx .jsx .c .h .cpp .cc .hpp .rs .go .sh .bash .sql .gradle .toml .yaml .yml .json .xml .css .scss | 按函数 / 顶层声明切段 |

限制与自动跳过：

- 单文件 ≤2MB；超过 2MB 或空文件跳过
- 目录递归 ≤8 层，单库最多 5000 个文件；以 `.` 开头的隐藏文件跳过
- 含 null 字节的二进制文件拒收（仅在白名单扩展名下才会读到内容）
- 编码：UTF-8 严格解码失败回退 GBK，中文老文件可直接索引
- 不支持 PDF / Word / Excel / PPT / 图片 / 音频——请先导出为 md 或 txt 再索引

### Key 与访问控制

- 服务启动即自动生成访问 Key（`sk-rag-…`），页面可复制、可重置
- 鉴权失败返回 401 + WWW-Authenticate；仅 `/health` 公开，其余接口（含状态）都在门内
- 检索默认只查文档库；聊天记忆需 `include_chat=1` 显式开启，且聊天记忆库不可删除

### 多库与检索

- 知识库列表：名称 + 文件数·块数 + 删除；换目录即新增库，检索跨全库
- 检索参数 GET/POST 完全对齐（query、k、min_score、include_chat、library_id、file_cap），k 上限 50
- 响应回显 `requested_k / k / min_score / file_cap / returned / candidates / libs`，参数是否生效由响应自证；

## 二、聊天记忆

- 聊天记录持久化（chat.db）：只存 user / assistant 正文，思考过程与工具结果不入库
- 「索引记忆」把历史对话切窗入知识库，支持时间衰减召回（半衰期 30 天）；记忆面板含索引 / 检索 / 召回开关 / 清空
- Chat 页新增知识库按钮：发送时自动注入知识库相关段落（默认 Top3，单段 ≤500 字、总量 ≤1500 字），气泡显示「知识库 N 段」，注入是否发生可观察；

## 三、对话与推理

- llama.cpp 基线升级：797de63b2 → 4e910a86e（+319 commit）；
- 启用 KV 前缀复用：四档默认 `--cache-reuse 256`，对「前缀相同、中间内容变化」的场景生效；需要关闭时在高级参数追加 `--cache-reuse 0`
- 思考流与正文彻底分离：思考内容不再混进聊天气泡、不再写入聊天记录与记忆库；无正文时显示「思考中… N 字」
- MoE 会话 n_ctx 越界由「拒绝」改为「截断」，修复无论是否开启思考都空回复的问题
- 修复界面冻结：测速、推理结束等耗时调用移出 JavaBridge 线程，轮询不再被阻塞
- **HTP 新增 v85 内核**（骁龙 8 Elite Gen5 / SM8850 机型可用）；

## 四、界面

- 主界面 5 tab → 3 tab（服务 / Chat / 设置）；新增服务聚合页：推理 / 搜索 / 知识库三卡，各带开关、完整地址、key复制、二级入口

## 五、搜索服务

- 新增首页：`GET /` 与 `/index.html` 返回服务说明页；
- 结果数上限 8 → 20；

## 六、已知问题

1. **NPU / MTP 档把 KV 量化手动改成 Q4_0 会崩**（进程 exit 134，HTP 内核只支持 f16 / f32 / q8_0 的 KV 写入）。默认 q8_0 安全；
2. **v85 内核仅完成静态验收**：由于没有 v85（SM8850 / 骁龙 8 Elite Gen5）设备，未做真机测试；非 v85 机型走的仍是原 v73–v81 路径；

## 安装

下载 `PocketOrca-LLM-v1.5.1-release.apk`

系统要求：Android 12 及以上，arm64，与 v1.5.0 同证书签名，直接覆盖安装即可

升级须知：

- 旧版本聊天记录里已混入的思考文本不会自动清除——如需清理，请「清空聊天记录」后重新「索引记忆」
- 升级后建议：①到知识库页复制新 Key 更新外部客户端；②如需清除旧思维链，清空聊天记录后重建索引；③NPU/MTP 档 KV 量化保持默认 q8_0
- 如遇异常想彻底重来：先在设置页「清除全部缓存、设置与已存 Key」+ 清空聊天记录，仍不行再卸载重装（会丢失已下载的模型）
