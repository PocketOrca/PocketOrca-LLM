## 1. 安装

**系统要求**：Android 8.0 及以上，arm64 设备。NPU/GPU 引擎仅限高通骁龙 8 系（详见发布页兼容性表格）。

1. 从 GitHub Releases 页下载最新版 APK（文件名形如 `PocketOrca-LLM-vX.X.X-vcXX-release.apk`，以 Release 页为准），点击安装（提示"未知来源"时允许）
2. 首次启动会依次弹出三个权限请求，**建议全部允许**：
   - **电池豁免**（允许后台运行）——保证息屏后服务不断连，拒绝后熄屏可能断连
   - **所有文件访问**——用于浏览手机里的 GGUF 模型文件
   - **通知权限**——用于常驻服务通知与状态监控

> 卸载重装后权限会重置，重新打开 App 会再次引导授权。

## 2. 下载模型

PocketOrca-LLM **不含任何模型文件**，需自行下载 GGUF 格式模型（推荐 4-bit 量化，Q4_K_M 或 Q4_0）。

**下载渠道（国内可直接访问）**：

| 渠道 | 地址 | 说明 |
|---|---|---|
| 魔搭 ModelScope | https://modelscope.cn | 阿里出品，国内速度最快，需注册 |
| hf-mirror | https://hf-mirror.com | HuggingFace 国内镜像，免注册 |
| HuggingFace | https://huggingface.co | 需科学上网 |

**推荐入门模型**（关键词搜索）：

| 模型 | 量化 | 体积 | 适合 |
|---|---|---|---|
| Qwen3-1.7B / Llama-3.2-1B | Q4_0 / Q4_K_M | 1–1.5 GB | 入门，速度快 |
| Qwen3-4B / Phi-4-mini | Q4_K_M | ~2.5 GB | 均衡 |
| Qwen2.5-7B | Q4_0 | 4–5 GB | 质量优先，需 12GB RAM 手机 |

> 三星 S25（8 Elite）实测：7B 用 NPU 引擎运行最稳定，稳定 10 t/s，NPU 发热低，长时间输出衰减不明显。

**存放位置**：下载后放到手机"下载"或任意目录均可，App 会浏览全盘查找。注意 Qwen3 系在 NPU 引擎有上游 bug，会自动引导切 GPU 引擎。

> **提示**：从电脑传输大模型到手机时，偶有传输不完整的情况（文件差几 MB 但服务仍能加载，生成会异常）。换新模型后如遇输出异常，先核对文件大小是否与来源一致。

## 3. 启动服务

1. 打开 App，进入「服务」页
2. 浏览选择 GGUF 模型文件
3. 选择引擎：
   - **NPU**：骁龙 8 Elite 及之后机型，速度最快、最省电（建议使用 4-bit Q4_0 模型文件，Q4_K_M 会回退到 GPU/CPU 运行）
   - **GPU**：骁龙 8 Gen 3 以上通用，兼容性好（已知 8 Gen 2 机型 GPU 可启动但输出乱码，仅在三星 S23 Ultra / Tab S9（OneUI 6.1）实测）
   - **CPU**：理论上支持所有 2023 年之后的安卓设备，请自行测试
4. 点「启动服务」，等待模型加载完成
5. 待启动完成后右上角有绿色指示灯显示 Server 正在运行中

> 模型加载与推理全部在手机本地完成；仅「远程 API 模式」（§8）需要联网。

**关键参数**（在「服务」页参数抽屉里）：

- **上下文长度 ctx**：模型能"记住"的对话总量，默认 4096；12GB RAM 建议 ≤32K（4B 模型实测）；7B/9B 模型建议 ≤8K；16GB 以上设备可自行尝试更大上下文
- **CPU 线程数**：0 = 自动
- **批处理 ubatch**：0 = 关闭
- **深度思考**：默认关闭；Qwen3 系等混合推理模型可开启
- **KV 卸载**：默认关闭；内存有限时可开启以降低内存占用
- **端口**：默认 8080，可修改，修改后需重启服务

## 4. 局域网连接

服务启动后，**同一 Wi-Fi 下的设备都可以连接**：

- **端点地址**：`http://<手机IP>:端口/v1`（IP 在服务页顶部显示）
- **API Key**：App 内设置的 Key（AES-GCM 加密存储），客户端填同样的值

**方式一：浏览器** —— 手机浏览器打开 `http://<手机IP>:8080` 直接对话

**方式二：OpenAI 兼容客户端**（电脑 / 平板 / 另一台手机），包括另一台设备上运行的 PocketOrca-LLM——其「命令行」页可用于测试局域网内及在线模型 API

| 客户端 | 平台 | 配置方法 |
|---|---|---|
| OpenWebUI | Docker / 电脑 | API 地址填 `http://<手机IP>:8080/v1`，Key 填 App 内 Key，模型名留空或填文件名 |
| ChatBox | 全平台 | 模型提供方选 "OpenAI 兼容"，同上 |
| SillyTavern | 全平台 | API 选 Text Completion 或 Chat Completion（OpenAI 兼容），同上 |

**命令行快速验证**（电脑上）：

```bash
curl http://<手机IP>:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ***" \
  -d '{"messages":[{"role":"user","content":"你好"}]}'
```

## 5. 引擎选择建议

| 你的手机 | 推荐 |
|---|---|
| 骁龙 8 Elite / 8 Elite Gen 5 | NPU（最快最省电）；Qwen3 系除外→GPU |
| 骁龙 8 Gen 3 | NPU 或 GPU |
| 骁龙 8 Gen 2 | GPU 或 CPU |
| 骁龙 8 Gen 1 及更早 / 联发科 | CPU |

> 上游 llama.cpp 对 Hexagon 的支持尚处早期，NPU 引擎仅对 Q4_0 等简单 4-bit 格式有原生 kernel；Q4_K_M 等常用格式会回退 CPU，速度掉回 CPU 水平。跑 NPU 请选 Q4_0 版模型。

## 6. 调参指南

「服务」页 /「命令行」页的参数抽屉，即时生效：

| 参数 | 作用 | 建议 |
|---|---|---|
| temperature | 随机性，越高越有创意 | 日常 0.7；写代码 0.2–0.4 |
| top_k | 每步只在概率前 K 个词里选 | 40 左右 |
| top_p | 累积概率截断 | 0.9 |
| min_p | 替代 top_p 的截断方式 | 0.05–0.1 |
| repeat_penalty | 重复惩罚 | 1.1；模型复读时调高 |
| system prompt | 系统提示词，定义角色 | 支持预设（默认/简洁/详细） |

## 7. Chat 页

App 内置对话页，两种模式：

- **本地模式**：直接和手机上运行的模型流式对话（速度、token 统计实时显示）
- **远程模式**：在「命令行」页开启"远程连接"后，Chat 页直连任意远程 OpenAI 兼容 API（比如你电脑上跑的大模型），流式输出

## 8. 远程 API 模式

「命令行」页可以连接另一台设备上运行的 llama.cpp 服务（或任何 OpenAI 兼容端点）：

1. 填 Base URL（如 `http://192.168.1.100:8080/v1`）和 API Key
2. 点「连接测试」，通过后选择模型
3. Chat 页自动切换到远程模式，CLI 页可直接发推理指令

## 9. 后台保活说明

**息屏 / 滑卡 / 拔电后服务持续在线**：

- 上滑清理 App 后，1.5 秒内自动复活并恢复服务
- 息屏后由系统闹钟保活，局域网端点持续可达
- 在 App 内点「停止」才是真正停止，不会被拉起
- 如遇个别 ROM 激进杀后台（如部分国产 ROM 的"深度睡眠"），请将 PocketOrca-LLM 加入系统设置的"自启动白名单"更稳

> 注意：复活后**正在生成的请求会继续**（接管孤儿进程），但系统可能曾短暂冻结服务——如果客户端报连接超时，重新发送即可。

## 10. 常见问题 FAQ

**Q：启动时报"无法加载模型"？**
先确认是 GGUF 格式（不是 .bin/.safetensors）；核对文件是否传输完整（对比文件大小）；RAM 越小用越小的模型：8GB 以下建议 4B 及以下，12GB 以下建议 9B 以下。

**Q：生成速度比宣传的慢？**
确认引擎是否跑在 NPU/GPU 上（服务页可见）；检查是否开了省电模式；长时间推理发热降频属正常现象。

**Q：电脑连不上手机？**
①手机和电脑必须在**同一 Wi-Fi**；②确认服务状态胶囊是"运行中"；③手机 IP 变了（重启路由器后常见），重新查看；④路由器开了"AP 隔离"的话会屏蔽设备互访，需在路由器设置里关闭。

**Q：输出乱码？**
骁龙 8 Gen 2 的 GPU 引擎 + Q4_K 系量化有已知驱动缺陷，改用 CPU 引擎或 Q4_0 量化。其他机型遇到乱码请到 GitHub 提 issue，附机型 + 引擎 + 模型量化格式。

**Q：NPU 引擎选项是灰的？**
你的 SoC 不在 NPU 支持列表（需骁龙 8 Elite 起步），或当前模型量化不被支持。用 GPU/CPU 引擎即可。

**Q：Qwen3 模型在 NPU 上卡死？**
已知上游 bug，App 会自动引导切换 GPU 引擎，按提示操作即可。

**Q：支持多用户 / 公网访问吗？**
设计为局域网自用，无鉴权体系（仅单 API Key），**不要暴露到公网**。

**Q：会出 iOS 版吗？**
不会。NPU 加速依赖高通 Hexagon 专有栈，iOS 无此通道，后续计划会采用其他底层技术开发。
