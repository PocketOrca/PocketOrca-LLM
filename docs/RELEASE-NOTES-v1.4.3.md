# PocketOrca-LLM v1.4.3 更新日志

**中文**

## 新特性

- 主要：集成 MoE 专家流式引擎（Apache-2.0）。35B 级 MoE 大模型（强烈建议使用 Qwen3.6-35B-A3B-Q4_K_M.gguf）在 12GB 手机上可运行：实测稳态约 5-6 token/s、首字约 3 秒（骁龙 8 Elite，三星 S25），输出与完整加载逐字节一致。建议 8 Elite 及以上机型测试使用 MoE 档位，老机型可尝试但未经充分测试。MoE 引擎为隐藏档位：浏览模型时做了模型自检，检测到 MoE 模型时会显示 MoE 档位；由于增加了模型类型自检，浏览模型时会有自检等待时间，请谅解
- MoE 模型一键导入：选中 GGUF 一键导入应用目录（建议开启 O_DIRECT 直读=提高专家流式读取性能）
- 本地服务支持局域网访问：加入是否开启对外服务开关（感谢酷安网友@阳家）
- 增加 API Key 鉴权（感谢 bilibili 网友@点点圈圈No1）

## 修复与改进

- 主要：增加了 NPU 引擎的模型预检
- 修复部分机型三键导航与界面重叠问题

## 安装

- 下载 `PocketOrca-LLM-v1.4.3-release.apk`
- 系统要求：Android 12 及以上，arm64
- 与 v1.4.2 同证书签名，可直接覆盖安装
