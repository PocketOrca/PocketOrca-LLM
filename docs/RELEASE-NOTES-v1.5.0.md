# PocketOrca-LLM v1.5.0 更新日志

本次更新的重点，是把这个 App 从「本地推理服务器」升级为「手机上的服务聚合器」：

新增**内置搜索服务**，接口对齐标准 searxng schema —— 手机本地即是一个类 SearXNG 实例，可直接为第三方 Agent / 客户端提供搜索能力，无需再搭中间服务。

## 一、搜索服务

- **标准接口**：`/search?format=json`，与 SearXNG 官方 schema 对齐，Agent 可即插即用
- **内置 6 个搜索引擎**：

  | 引擎 | 网络 | 说明 |
  |---|---|---|
  | Bing | 国内/国际 | 双 host 互补，结果异常自动切换重试 |
  | 百度 | 国内 | 移动端页面解析；受对方风控影响可能偶发失败，失败时静默跳过，不影响其它引擎出结果 |
  | 搜狗 | 国内 | — |
  | DuckDuckGo | 外网 | lite 端点 |
  | Wikipedia | 外网 | — |
  | GitHub | 外网 | 仓库搜索，显示 ★ 数 |

  国内网络建议使用 **Bing / 百度 / 搜狗**。
- **结构化直答**：搜「××股价」直接出〔行情〕行（现价 / 涨跌幅 / 时间），搜「××天气」出〔天气〕行；识别不到则完全回退普通搜索，不打扰。
- **单引擎熔断**：连续失败自动挂起 30 秒，失败原因（timeout / dns / http）写入接口的 `unresponsive_engines`，便于排查。
- **端口可配置**：默认 8081，范围 1024–65535，且不可与 8080 冲突；通知栏与页面地址行跟随新端口，改端口后需重启搜索服务生效。
- **搜索页重构**：状态 / 地址（可复制）/ 端口三行 + 「启动搜索服务」按钮（启动中 / 运行中 / 停止 / 重试 四态）；引擎卡改为折叠抽屉，一行一引擎 + 右侧开关，改动即时生效；测速按钮可测试当前网络到各引擎的连通情况。

## 二、对话与推理

- **Chat 联网搜索**：本地推理服务与搜索服务均已启动时，开启 Chat 页联网搜索按钮即可边搜边答。
- **最大输出 1024 → 8192 token**：长回复不再被截断。
- **流式回复自由滚动**：输出过程中手指上滑即停止跟随，右下出现 ↓ 回底按钮，点它或滑回底部自动恢复跟随。
- **「启用 MOE 服务」开关**（设置页，默认关闭）：关闭时不读取 GGUF 文件头做 MoE 检测，提升软件运行速度。

## 三、其它改进

- 服务端点显示补 `/v1`；未开启「端口对外开放」时显示 `127.0.0.1`，不再一律显示局域网 IP。
- **检测更新功能从此版本开始启用**。
- 引擎日志折叠卡从搜索页移至 CLI 页底部。
