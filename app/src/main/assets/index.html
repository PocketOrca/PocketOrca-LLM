关于本软件

      
基于 llama.cpp（MIT 协议）开发，充分发挥手机 SoC 的算力潜力——让 NPU、GPU 与 CPU 协同工作，在本地运行大语言模型。

      
本软件仅在有限机型上完成测试，实际兼容性与性能因机型和系统版本而异，请以您的实测为准。

    


    

      
使用须知

      
· 仅支持 GGUF 格式模型，软件本身不含任何模型文件，请自行下载

      
· 推理时长时间高负载占用 CPU / GPU / NPU，可能导致发热、降频、卡顿，极端情况下其他应用可能被系统终止

      
· 长时间运行请保持通风散热，勿覆盖机身；出现过热告警请立即停止使用

      
· 模型的质量与输出内容由所加载的模型决定，与本软件无关
